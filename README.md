# Movie Night Planner

A responsive React application for searching movies, viewing details, and managing favorites.

## Live Demo
https://matgeroina.github.io/movie-night-planner-pj/

## Tech Stack
- React
- React Router
- JavaScript (ES6+)
- CSS (Grid, Flexbox)
- OMDb API
- localStorage

## Features
- Search movies by title
- View detailed movie details
- Add and remove favorites
- Persist favorites using localStorage
- Responsive layout for mobile and desktop
- Fallback handling for missing posters

## Run Locally
```bash
git clone https://github.com/matgeroina/movie-night-planner-pj.git
cd movie-night-planner-pj
npm install
npm run dev
